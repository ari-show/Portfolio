# Security Policy

## Supported Versions

Only the latest version deployed from the `main` branch (https://ari-show.com) is supported.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report them privately via GitHub's
[Private vulnerability reporting](https://github.com/ari-show/Portfolio/security/advisories/new)
("Security" tab → "Report a vulnerability").

I will acknowledge the report as soon as possible and keep you updated on the fix.
